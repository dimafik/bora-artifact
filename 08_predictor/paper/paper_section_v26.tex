\section{Learning the Sub-Leader Score Function}
\label{sec:learn-score}

The S-Raft framework~\cite{Sraft2026} ranks sub-leader candidates via
the closed-form score
\begin{equation}
  \label{eq:sraft-score}
  Score_i = w_{cc}\, CC_i + w_{rtt}\, \mathrm{NORMALIZE}(RTT_i),
\end{equation}
with $w_{cc}=0.6$, $w_{rtt}=0.4$ and
$\mathrm{NORMALIZE}(RTT_i)=(RTT_{\max}-RTT_i)/(RTT_{\max}-RTT_{\min})$.
Equation~\eqref{eq:sraft-score} assumes stationary network and stationary
workload. We show this assumption is empirically violated under multi-AZ
deployment and propose a learned, theory-preserving replacement.

\subsection{Predictor $\mathcal{P}$}
\label{sec:predictor}

Let $\mathbf{x}_i^{(t)}\in\mathbb{R}^{K\times d}$ denote a per-node window
of $K=60$ heartbeat ticks across $d=8$ channels:
$(cc, CC, rtt, RTT, T_{commit}, \delta CC, \delta RTT, \text{designation})$.
The predictor is a 4-layer Transformer encoder
$\mathrm{Enc}_\theta:\mathbb{R}^{K\times d}\!\to\!\mathbb{R}^{d_m}$ with
$d_m{=}64$, followed by three heads
\begin{align}
  \widehat{Score}_i^{t+H} &= \sigma\bigl(g_S(z)\bigr),\;
    H\in\{30,60,90\}\text{s},\;\sigma\!=\!\mathrm{sigmoid},\\
  \widehat{p}_{\mathrm{anom},i} &= \sigma\bigl(g_A(z)\bigr),\\
  \widehat{p}_{\mathrm{degr},i} &= \sigma\bigl(g_D(z)\bigr),
\end{align}
where $z=\mathrm{Mean}_k\!\bigl(\mathrm{Enc}_\theta(\mathbf{x}_i^{(t)})\bigr)$ and
$g_S,g_A,g_D$ are 2-layer MLPs.

The score head is trained with the pinball loss at quantiles
$\tau\in\{0.1,0.5,0.9\}$ to expose calibrated prediction intervals. The
anomaly head is trained on synthetic Byzantine traces (ack-spoofing with
delayed commit); the degradation head uses 1-hour-ahead binary labels
derived from injected garbage-collection stalls.

\subsection{Advice Interface}

The predictor produces an advice tuple
$\mathcal{A}=\langle \text{ok},\widehat{i}_{\text{prom}},\mathcal{B},\mathcal{D}\rangle$,
where $\text{ok}$ flags sufficient confidence, $\widehat{i}_{\text{prom}}$ is
the pre-promote nominee, $\mathcal{B}\subset\mathcal{N}$ is the
anomaly-flagged blacklist, and $\mathcal{D}$ holds maintenance warnings.
$\mathcal{A}$ enters S-Raft Algorithm 1 \emph{only} as a post-rank filter:
\begin{itemize}\setlength\itemsep{1pt}
  \item If $\text{ok}=\bot$, S-Raft proceeds with Eq.~\eqref{eq:sraft-score} unchanged.
  \item Else: $\textsc{Rank}\leftarrow\textsc{Rank}\setminus\mathcal{B}$,
        subject to $|\mathcal{B}|<f$.
  \item If $\widehat{i}_{\text{prom}}\in\text{Top-2}(\textsc{Rank})$,
        promote $\widehat{i}_{\text{prom}}$ to primary candidate slot.
  \item Maintenance warnings are emitted to an ops sink; no consensus impact.
\end{itemize}

\subsection{Augmentation Safety Theorem}
\label{sec:safety}

\begin{theorem}[Augmentation Safety]
\label{thm:safety}
Let $\mathrm{S\text{-}Raft}^{+\mathcal{A}}$ denote S-Raft with the advice
interface above. Then S-Raft Theorems 1 (Election Safety), 2 (Detection
Priority), and 3 (Bounded Cascading Recovery) hold under
$\mathrm{S\text{-}Raft}^{+\mathcal{A}}$ for every advice realisation.
Moreover, the cascading recovery bound is monotonically tightened:
\begin{equation}
  \label{eq:recovery-bound}
  t_{\mathrm{recover}}^{+\mathcal{A}} \;\le\;
  t_{\mathrm{recover}}^{\mathrm{baseline}}
  \qquad \forall\,\omega \in \Omega.
\end{equation}
\end{theorem}

\begin{proof}[Proof sketch]
\textit{T1 (Election Safety).} The advice modifies the candidate ordering
only \emph{after} ranking; quorum-vote majority gating is unchanged. Term
monotonicity and one-leader-per-term are preserved by the original Raft
argument verbatim.

\textit{T2 (Detection Priority).} Tier timeouts
$T_{\mathrm{primary}}\!<\!T_{\mathrm{secondary}}\!<\!T_{\mathrm{follower}}$
are unaffected by $\mathcal{A}$. Forced tier reassignment by maintenance
warning only widens the gap $G$, so the split-vote bound (S-Raft Lemma 1)
holds with the same constants.

\textit{T3 (Bounded Cascading Recovery).} If $\mathcal{A}$ has
pre-promoted at $t<t_{\mathrm{kill}}^{(1)}$, the recovery completes after
a single $T_{\mathrm{Promote}}^{1\mathrm{RTT}}$ round, giving
$T_{\mathrm{Promote}}^{1\mathrm{RTT}}+2\Delta$. Since
$T_{\mathrm{secondary}}^{\max}\ge T_{\mathrm{Promote}}^{1\mathrm{RTT}}$ by
tier definition, Eq.~\eqref{eq:recovery-bound} holds. When
$\text{ok}=\bot$, the baseline bound applies.

\textit{Byzantine.} The constraint $|\mathcal{B}|<f$ guarantees the
remaining set retains a quorum overlap under $f<N/3$. False positives in
$\mathcal{B}$ reduce liveness rate (recoverable in next epoch) without
affecting safety.
\end{proof}

\subsection{Three Operating Modes from One Predictor}

\paragraph{Mode 1: Predictive Promotion.}
At each tick the leader queries $\mathcal{P}$ for
$\widehat{Score}_i^{t+30s}$. When the predicted top-1 differs from the
current primary slot by more than $\theta_h+\sigma_{\widehat{S}}$ (the
S-Raft hysteresis plus prediction-interval half-width), an
``advance promotion'' message piggybacks on the next AppendEntries. By
Theorem~\ref{thm:safety} the recovery bound only tightens.

\paragraph{Mode 2: Anomaly-Based Security.}
The anomaly head implements a single-class detector trained on synthetic
ack-spoofing Byzantine behaviour. A candidate exhibiting
$\widehat{p}_{\mathrm{anom},i}>\tau_A$ (we use $\tau_A=0.5$) is added to
$\mathcal{B}$ for the next $K_B=64$ heartbeat windows. SHAP feature
attributions are emitted per blacklist event for audit.

\paragraph{Mode 3: Predictive Maintenance.}
The degradation head forecasts $\Pr[\,T_{\mathrm{follower}}^{\max}\text{ exceeded within 1h}\,]$.
When $\widehat{p}_{\mathrm{degr},i}>\tau_D$ ($\tau_D=0.3$), an alert is
emitted; optionally the node is force-relegated to follower tier so
hardware can be replaced under quorum guarantee. This subsystem operates
entirely outside the consensus critical path.

\subsection{Why Learn What is Already Closed Form}

A skeptic may object that Eq.~\eqref{eq:sraft-score} is already a clean
function of measured signals. Three arguments:

\begin{enumerate}\setlength\itemsep{1pt}
\item[\textit{(i)}] \emph{Non-stationarity.} The hand-tuned weights
$w_{cc}=0.6, w_{rtt}=0.4$ are stationary; real multi-AZ traffic is not.
Our predictor's effective weights vary across the input window: under
heavy write workload the network responsiveness loses ranking importance
relative to commit contribution.
\item[\textit{(ii)}] \emph{Future-state planning.} Promotion at
$\widehat{Score}^{t+30s}$ enables \emph{pre-promotion} before cascade,
turning Theorem 3's worst case into a $1$-RTT path.
\item[\textit{(iii)}] \emph{Backbone reuse.} The same encoder produces
anomaly and degradation signals at marginal cost. Replacing
Eq.~\eqref{eq:sraft-score} by a learned function yields safety,
maintenance, and prediction simultaneously from a single 0.56\,MB model.
\end{enumerate}
