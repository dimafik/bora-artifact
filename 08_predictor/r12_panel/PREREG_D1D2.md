# D1 / D2 — 사전 등록 (실행 전 작성)

작성: 2026-08-20, 실행 **전**

## 왜 하는가 — 네 차례 실험이 잘못된 과제를 쟀다

패널 · H1b/H3 · R1 · R2b는 모두 **"창 하나 → 정상/공격" 이진 분류**였다.
그런데 배포된 데몬이 방출하는 것은 이진 판정이 아니라 **노드 ID 집합**이다.

    Bt=[3] r=0 cap=2

알고리즘 1의 출력은 집합 `B_t`이고, 오탐 1건은 **엉뚱한 노드를 후보에서 배제**하는
것이다. 실험 #9가 그 대가를 쟀다(ALR 제거 시 오탐이 리더를 159회 교체).
**이진 AUC가 1.000이어도 귀속이 틀리면 시스템은 잘못된 노드를 차단한다.**
그 축을 한 번도 재지 않았다.

D2는 다른 종류의 공백이다. 논문은 **N=5,7,9,11,15,21**에서 돌고 §III-H가 joint
consensus 재구성을 다룬다. **노드 수가 실행 중 바뀐다.** 고정 크기 입력을 전제한
구조는 성능 이전에 **배포가 불가능**하다. 이것도 잰 적이 없다.

---

## D1 — 귀속: 누가 이상인가

**과제.** N=5 노드가 공통 지터를 공유하고, **정확히 하나**가 열화한다(비상관 잡음
추가). 각 노드 창은 개별 정규화하므로 **노드 하나만 보면 구별 불가**.
출력은 **어느 노드인가**이며 지표는 **top-1 식별 정확도**(우연 = 0.20).

**비교 대상 — 모두 노드별 점수를 내되 관계 연산 방식이 다르다.**

| 구조 | 관계 연산 | 정체성 보존 |
|---|---|---|
| per-node (관계 없음) | 없음 | 보존 |
| **평균편차 특징 + per-node** | 시점별 노드 평균 빼기 (수작업) | 보존 |
| **Conv2d (노드축 커널 3)** | 이웃 노드만 | 보존 |
| **GRU over nodes** | 노드 축 순차 | 보존 |
| **Node self-attention** | 전 노드 쌍 | 보존 |

**Conv2d와 GRU-over-nodes는 노드에 순서가 있다고 가정한다.** 오더러에는 자연적
순서가 없으므로 이것이 원리적 약점인지 D1이 함께 드러낸다.

## D2 — 가변 클러스터 크기와 순열

**과제.** **N=5로만 학습** → N=7, 9, 11, 21에서 시험. 추가로 시험 시 **노드 순서를
무작위 치환**한다.

| 구조 | 가변 N | 순열 동변 |
|---|---|---|
| MLP concat | ✗ (입력 차원 고정) | ✗ |
| Conv2d 노드 커널 | ✗ (커널 크기 고정) | ✗ |
| GRU over nodes | ○ (가변 길이 가능) | ✗ (순서 학습) |
| **Node self-attention** | **○** | **○** |

**공정성.** 고정 구조에도 가변 N 대응(노드 축 적응 풀링·패딩)을 부여하고, 그렇게
해도 되는지를 측정한다. 대응을 주지 않고 "불가능하다"고 쓰면 편향이다.

## 예측 (실행 전 기록)

1. **D1에서 어텐션이 1위.** 관계 연산과 정체성 보존을 동시에 하는 유일한 구조.
   Conv2d·GRU-over-nodes는 노드 순서 가정 때문에 뒤질 것이다.
2. **평균편차 수작업 특징이 만만치 않을 것이다.** 이 과제의 신호가 "평균에서
   벗어난 노드"라면 수작업 특징이 학습 구조를 이길 수도 있다.
3. **D2에서 어텐션만 N 전이가 된다.** 나머지는 N=5→21에서 크게 저하한다.
4. **순열 시험에서 Conv2d·GRU-over-nodes가 무너진다.**

## 판정 기준 (실행 전 고정)

| 관측 | 결론 |
|---|---|
| D1·D2 둘 다 어텐션 우위 | **아키텍처 선택 정당화.** 근거는 "어텐션이 좋다"가 아니라 **"BORA의 출력이 집합이고 N이 가변이므로 집합 연산이 필요하다"** |
| D1만 우위 | 귀속을 근거로 삼고 N 전이는 공시 |
| D2만 우위 | 배포 가능성만 근거. 성능 주장은 하지 않음 |
| 둘 다 아님 | **GRU 권장 확정.** 네 차례가 아니라 여섯 차례 검증된 결론으로 기록 |

## 미리 정한 정직성 조건

- **수작업 평균편차 특징이 이기면 그대로 쓴다.** 학습 구조가 필요 없다는 뜻이며,
  그 편이 배포에 유리하다.
- D1·D2가 어텐션에 유리한 과제라는 **반론을 원고에 먼저 적는다.** 방어는 하나뿐이며,
  그것은 **이 과제가 배포 현실이라는 사실**이다 — 데몬은 실제로 노드 ID를 뽑고
  실제로 N=5~21에서 돈다.
- 이전 결과(패널·H1b·H3·R1·R2b)를 **지우지 않는다.** 어텐션이 불필요한 영역과
  필요한 영역을 **둘 다** 보고한다.
