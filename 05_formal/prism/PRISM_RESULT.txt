=== PRISM probabilistic verification of BORA leader-election convergence ===
Tool: PRISM 4.8.1 (DTMC engine).  Models: election.pm (W=2, worst case),
election_w3.pm (W=3), election_k.pm (round-bounded).  Run via run_prism.sh
(ubuntu:24.04 container + JRE).  This supplies the PROBABILISTIC part of the
liveness Proposition that (non-probabilistic) TLA+/TLAPS cannot express.

Model: within BORA's eligible set E_t (|E_t| = NE, blacklisted nodes withhold
their campaign but still vote; the minimum-hold rule keeps NE >= ceil((N+1)/2)),
each election round every eligible candidate draws a uniform timeout slot in
{0..W-1}; the UNIQUE-smallest-slot candidate wins, a tie is a split vote and the
round repeats.  Per-round success q = NE/2^NE for W=2 (exact, confirmed below).

--- QUALITATIVE: w.p.1 convergence  P>=1 [ F leader ]  (TLA+ cannot state this) ---
  W=2, NE=3 : true     (P=?[F leader] = 1.0 exact)
  W=2, NE=4 : true     (P=?[F leader] = 1.0 exact)
  W=2, NE=5 : true     (P=?[F leader] = 1.0 exact)

--- EXPECTED ROUNDS  R{"rounds"}=? [ F leader ]  (= 1/q) ---
            W=2 (worst-case 2-slot window)     W=3 (wider window)

  NE=5 :    6.400   (= 1 / (5/32))             2.859
  => wider timeout window => higher q => faster; W=2 is the adversarial worst case.
